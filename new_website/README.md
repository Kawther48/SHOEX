# SHOEX — a study in sneakers

A JavaScript-only Astro storefront demonstration for a fictional luxury sneaker boutique.
The eight transparent sneaker photographs come from PNGimg.com and are reused unchanged
on the collection wall, product pages, and in the shopping bag. Their individual source
pages are linked from the product galleries; the collection is credited in the footer.
The images are licensed under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)
and are used for this non-commercial, no-payment demonstration.

## Run locally

```sh
npm install
npm run dev
```

The production build can be checked with `npm run build`. The demonstration shopping
bag is saved to this browser's local storage; checkout and payment are intentionally
disabled. Every page states that this is not a real store.
